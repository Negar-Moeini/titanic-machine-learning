# Titanic Survival Prediction Using Machine Learning

## Overview

This project analyzes the Titanic passenger dataset and uses machine learning techniques to predict passenger survival.

## Objectives

- Analyze the Titanic dataset
- Perform data preprocessing
- Explore relationships between passenger features
- Build machine learning models
- Evaluate and compare model performance
- Apply clustering using K-Means

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Models

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest
- K-Means Clustering

## Dataset

The dataset contains information about Titanic passengers, including:

- Passenger class
- Age
- Sex
- Fare
- Embarkation port
- Survival status

## Results

The classification models were trained and evaluated on the Titanic dataset. Model accuracy was compared to identify the best-performing model.
